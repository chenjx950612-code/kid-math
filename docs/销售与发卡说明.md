# 销售与发卡说明（卖家操作手册）

商业模式：**自托管 + 年费卡密**。一个卡密 = 一个家庭，家庭内多台设备用同一 PIN 登录不限设备数。

## 一、发卡流程

1. 打开你的卡密管理后台：`https://lic.你的域名.com/admin`（本地则是 `http://飞牛IP:4444/admin`）。
2. 输入管理密码登录。
3. 「生成卡密」：填有效期天数（默认 365），点生成，把 `MATH-XXXX-XXXX-XXXX` 格式的卡密复制发给买家。
4. 买家部署主系统后，打开网页 → 「创建家庭」→ 输入自家 PIN + 卡密 → 激活成功，进入系统。

## 二、一个卡密对应什么

- **一个卡密 = 一个家庭**：创建家庭时卡密与 PIN、以及那台机器（installationId）绑定。
- 同一卡密在**任何机器**上再次创建家庭都会失败（提示"该卡密已激活使用"）。
- 家庭内**多台设备**（手机/Pad）用**同一个 PIN** 即可加入共享数据，**不需要卡密、不限台数**。
- 买家**改 PIN 后绑定关系自动同步**到卡密服务器（下次联网校验生效）。

## 三、续费

- 到期前：买家系统会提示剩余天数；到期后业务锁定，显示续费页。
- **方式 1（买家自助换码）**：你给买家生成一个新卡密，买家在续费页输入即可，有效期从新卡密起算。
- **方式 2（原码延期）**：在管理后台「列表」里找到该卡密点「续期」，输入延长的天数。买家系统每 6 小时在线校验一次，会自动生效，买家无需操作。

## 四、吊销 / 防共享

- 发现某卡密被共享/违约：管理后台点「吊销」。买家系统最迟 6 小时（启动时立即）校验到失效，业务被锁定。
- 卡密列表里能看到：状态（未使用/已激活/已吊销）、剩余天数、到期日、绑定的机器（机器 ID 前 8 位，用于核对是谁在用）。

## 五、断网容错（默认行为）

- 已激活家庭在**连不上你的卡密服务器**时继续可用（本地存有到期时间，到期才锁）。
- 仅「创建新家庭 / 续费 / 吊销生效」需要在线。所以请保证你的飞牛稳定在线。

## 六、售卖建议

- 每台买家 NAS 一份部署，数据在买家手里，你只需维护卡密服务器（一个小容器）。
- 建议把买家信息记在卡密列表的绑定机器一栏附近（可用备注或单独表格：卡密 → 买家微信/昵称 → 到期日）。
- 涨价/促销：直接通过「续期天数」控制，灵活。
