# 销售与发卡说明（卖家操作手册 · 离线卡密版）

商业模式：**自托管 + 年费卡密，纯离线**。一个卡密 = 一个家庭，家庭内多台设备用同一 PIN 登录不限设备数。

## 一、卖家要准备的东西

- 一台电脑（Windows/Mac/Linux 都行，装 Node.js ≥ 18 或直接用项目里的 node）。
- 项目代码（`tools/genkey.cjs` 就是发卡工具）。
- **没有服务器、没有域名、没有任何要维护的在线服务**。

## 二、发卡流程（每次卖一张卡密，一分钟搞定）

在项目目录下执行：

```bash
node tools/genkey.cjs          # 默认 365 天（一年）
node tools/genkey.cjs 730      # 两年
node tools/genkey.cjs 30       # 试用一个月
```

会输出：
```
卡密：MATH-BFUF-V9TR-RPY.-UXZL-OXN6-HSRW-HKMV-SSDQ-ZQ
有效期：365 天（2027/8/6 到期）
```

把卡密复制发给买家即可。**建议自己记台账**：卡密 → 买家昵称 → 到期日（工具会打印到期日）。

## 三、买家侧（把这段发给买家）

1. 部署主系统（和普通部署一样：传代码 → `docker compose up -d` 或飞牛图形界面）。
2. 打开网页 → 点「**创建家庭**」标签 → 输入自家 PIN + 卡密 → 创建成功即激活。
3. 家里其他设备：「加入家庭」→ 只输 PIN 即可共享，不限台数、不需要卡密。
4. 部署教程见《买家部署激活手册》。

## 四、续费

- 到期前网页会提示剩余天数（设置页也能看，剩不到 14 天会提醒）。
- 到期后系统锁定，显示续费页。买家联系你 → 你 `node tools/genkey.cjs` 生成新卡密 → 买家在续费页输入 → 立即恢复（有效期从新卡密起算）。
- 一个家庭同时只需要一个卡密；续费后旧卡密作废（被新卡密覆盖）。

## 五、这个方案的边界（卖之前心里有数）

- ✅ 零运维：不用服务器、不用联网、买家断网也能激活和使用。
- ⚠️ **防不住卡密复制**：卡密被转发给其他人时，对方在自己机器上也能激活。熟人/小范围信任场景没问题。
- ⚠️ **无法远程吊销**：出了纠纷不能远程锁定买家（只能到期等自然失效）。
- ⚠️ **密钥内置在代码里**：卡密验签密钥（`server.js` 和 `tools/genkey.cjs` 里的 `LICENSE_SECRET`，默认 `kid-math-license-v1-2026`）买家拿得到，懂技术的人理论上能自己造卡密。小范围可接受。

### 想更安全？改密钥
1. 两处都改成同一个自定义值：`server.js` 的 `LICENSE_SECRET` 常量，以及执行发卡时设环境变量：
   ```bash
   LICENSE_SECRET=你的新密钥 node tools/genkey.cjs 365
   ```
2. 买家部署时在 `docker-compose.yml` 环境变量里加 `LICENSE_SECRET=你的新密钥`（与发卡密钥一致），否则验签失败。
3. ⚠️ 改密钥后**已发出的旧卡密全部作废**，所以要么一开始就改好，要么只在发售前改。

### 需要更强管控（未来规模化）时
再考虑中心服务器方案（卡密存在你服务器上、可吊销、可统计）。当前离线版零运维，适合先小范围卖。
