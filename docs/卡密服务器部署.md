# 卡密服务器部署指南（卖家）

卡密服务器（license-server）负责：生成卡密、激活绑定（卡密 + PIN + 机器指纹）、续费、吊销。
它跑在**你自己的飞牛 NAS** 上，买家主系统通过公网 HTTPS 调用它。**这份代码只在你这儿，不会打包给买家。**

## 1. 在飞牛上部署

1. 把项目目录（含 `license-server/`）上传到飞牛，或在飞牛上 `git clone https://github.com/chenjx950612-code/kid-math.git`。
2. 进入目录并启动：

```bash
cd license-server
# 先改 docker-compose.yml 里的 ADMIN_PASSWORD（卖家管理后台密码，务必改掉默认值 061204）
docker compose up -d --build
```

- 服务监听 **4444** 端口，卡密数据持久化在 `license-server/data/licenses.json`（飞牛文件管理器可直接看到）。
- 本机验证：浏览器打开 `http://飞牛IP:4444/admin` 应看到管理后台。

## 2. 公网暴露（买家要能访问）

买家主系统需要能通过 HTTPS 访问卡密服务器。两种方式任选：

### 方式 A：子域名反代（推荐，需有域名 + 公网 IP）
1. 在域名服务商把 `lic.你的域名.com` 解析到你的公网 IP（A 记录）。
2. 在飞牛的反向代理（或 NPM）里新增规则：`lic.你的域名.com → 127.0.0.1:4444`，启用 SSL 证书。
3. 测试：浏览器打开 `https://lic.你的域名.com/admin` 能打开即成功。

### 方式 B：仅端口映射（内网穿透/端口转发）
1. 在路由器或飞牛上把公网某端口（如 44440）转发到内网 4444。
2. 买家配置时填 `http://公网IP:44440`（注意：走 HTTP 明文，卡密和 PIN 有被截获风险，推荐方式 A）。

## 3. 安全注意
- 立即修改 `ADMIN_PASSWORD`（默认 061204）。
- 管理后台建议只在自己信任的网络访问；或通过飞牛防火墙限制来源 IP。
- 定期备份 `license-server/data/licenses.json`（它就是你的"账本"）。

## 4. 买家怎么配置

买家部署主系统时，在 `docker-compose.yml` 的 `LICENSE_SERVER_URL` 填你的卡密服务器地址：

```yaml
- LICENSE_SERVER_URL=https://lic.你的域名.com
```

填好重启后，买家打开网页 → 切到「创建家庭」→ 输入 PIN + 你发的卡密 → 激活成功即可使用。
