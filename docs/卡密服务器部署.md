# 卡密服务器部署与发卡 · 超详细操作手册（卖家）

> 这是你（卖家）的完整操作手册：把卡密服务器跑在你的飞牛上 → 公网暴露 → 生成卡密卖给买家 → 买家部署激活。
> 全程 4 个角色区分清楚：
> - **你的飞牛**：跑「卡密服务器」（新容器，管卡密账本）+ 你自己的「主系统」（老容器，自己家用）
> - **买家的 NAS**：跑「主系统」（同一个项目，激活后给买家孩子用）
> - **管理后台** `https://lic.你的域名.com/admin`：你登录生成卡密用
> - **买家网页** `https://你的域名:3333`：买家孩子用

---

## 第 0 步：确认你的飞牛能 SSH + 有公网域名

- SSH：飞牛「设置 → 服务 → SSH」打开，用终端连上：`ssh 你的用户名@飞牛内网IP`
- 域名：如果你还没有域名，先去域名服务商买一个（如 `example.com`，一年几十元）；后文以 `lic.你的域名.com` 为例（可换成任意子域名）。

---

## 第 1 步：把代码放到飞牛（含卡密服务器目录）

### 方式 A：SSH 里 git clone（推荐，后续升级方便）
```bash
cd /vol1/1000/docker          # 进到你想放项目的目录（路径按你飞牛实际目录）
git clone https://github.com/chenjx950612-code/kid-math.git
cd kid-math
ls                            # 应该能看到 license-server 目录
```

### 方式 B：File Station 上传
1. 飞牛「File Station」新建文件夹（如 `docker/kid-math`）。
2. 把电脑上整个项目文件夹里的**所有内容**（含 `license-server/` 目录）拖进去上传。

> 注意：卡密服务器只在你这台飞牛上跑，**不要**把 `license-server` 目录单独发给买家（买家只需要主系统）。

---

## 第 2 步：修改卡密服务器的管理员密码（必做！）

用飞牛自带的文本编辑器，或 SSH 里执行：

```bash
nano license-server/docker-compose.yml
```

找到这一行，把 `061204` 改成你自己的强密码（如 `MySales2026#`）：

```yaml
      - ADMIN_PASSWORD=061204
```

改完保存（nano：`Ctrl+O` 回车保存，`Ctrl+X` 退出）。

---

## 第 3 步：启动卡密服务器

```bash
cd /vol1/1000/docker/kid-math/license-server
docker compose up -d --build
```

首次会拉取 node:18-alpine 并构建，约 1~2 分钟。完成后验证：

```bash
docker ps                      # 看到 kid-math-license 容器 Up 即可
curl http://localhost:4444/admin | head -c 100   # 能看到 HTML 即正常
```

卡密数据会存到 `license-server/data/licenses.json`，飞牛文件管理器可直接看到，**记得定期备份这个文件**（它就是你的"销售账本"）。

---

## 第 4 步：本机先验证管理后台

浏览器打开（同一局域网）：`http://飞牛内网IP:4444/admin`

应该看到「🔑 卡密管理后台」页面，输入第 2 步设置的密码可登录。

> 打不开？检查：容器是否 Up（`docker ps`）、防火墙/飞牛是否放行 4444 端口。

---

## 第 5 步：公网暴露（买家系统要能访问到）

### 方式 A：子域名 + 反代 + SSL（推荐，最安全）

**5A-1 域名解析**：登录域名服务商控制台，添加一条 **A 记录**：
```
主机记录：lic         记录类型：A         记录值：你的公网IP
```
> 动态 IP 用户：用飞牛自带 DDNS 或花生壳，把 `lic.你的域名.com` 指到动态域名即可。

**5A-2 端口转发**：登录家用路由器，把公网 `80`（和 `443`）端口转发到飞牛内网 IP（反代要用）。若飞牛反代直接占 80/443 则不用转。

**5A-3 配置反代**（二选一）：
- 飞牛自带「反向代理」：新建规则 → 域名 `lic.你的域名.com` → 目标 `http://127.0.0.1:4444` → 开启 SSL，用 Let's Encrypt 自动申请证书。
- 或 Nginx Proxy Manager：Proxy Hosts → Add → Domain Names 填 `lic.你的域名.com` → Forward Hostname `127.0.0.1` / Port `4444` → SSL 标签页选 "Request a new SSL Certificate"。

**5A-4 验证**：外网浏览器打开 `https://lic.你的域名.com/admin`，能出现管理后台即成功。

### 方式 B：只映射端口（临时/内网穿透用，有风险）
- 路由器把公网某端口（如 `44440`）转发到飞牛内网 `4444`。
- 买家配置填 `http://公网IP:44440`。⚠️ 明文 HTTP 会暴露卡密和 PIN，**只适合自己测试**，正式卖请用方式 A。

---

## 第 6 步：生成卡密发给买家（发卡）

1. 打开 `https://lic.你的域名.com/admin`，输入管理密码。
2. 「生成卡密」框里填有效期天数（**默认 365 = 一年**），点「生成卡密」。
3. 页面会显示 `MATH-XXXX-XXXX-XXXX` 格式的卡密，**复制发给买家**。
4. 一个卡密 = 一个家庭。买家一个家庭发一张；第 2 个家庭要买第 2 张。

> 卡密列表里能看到每张卡的状态（未使用/已激活/已吊销）、剩余天数、绑定机器 ID（前 8 位）。发卡后建议自己记一份"卡密 → 买家昵称 → 到期日"的台账（管理后台暂未内置备注，可在列表对照）。

---

## 第 7 步：买家侧部署 + 激活（把这节发给买家）

### 买家部署主系统（和普通部署完全一样）
```bash
cd /vol1/1000/docker
git clone https://github.com/chenjx950612-code/kid-math.git
cd kid-math
```

编辑根目录 `docker-compose.yml`，在 `environment:` 里把卡密服务器地址填上（**关键一步**）：

```yaml
      - LICENSE_SERVER_URL=https://lic.你的域名.com
```

启动：
```bash
docker compose up -d --build
```

### 买家激活
1. 浏览器打开 `https://你的域名:3333`（或局域网 IP:3333）。
2. 首次进入是「加入家庭 / 创建家庭」两个标签页 → 点 **「创建家庭」**。
3. 填自家 PIN（如 `1234`）+ 你发的卡密（`MATH-XXXX-XXXX-XXXX`）→ 点「创建家庭」。
4. 显示「✅ 家庭已创建」即激活成功，有效期一年。
5. 家里其他设备（手机/Pad）打开网页 → 「加入家庭」→ 只输 PIN 即可共享，**不需要卡密、不限台数**。

---

## 第 8 步：续费 / 吊销（日常运营）

### 续费方式 1：买家自助换新卡密（推荐）
到期后买家网页会锁定并显示续费页 → 你生成一张**新卡密**发给买家 → 买家在续费页输入 → 立即生效（有效期从新卡密起算）。

### 续费方式 2：原卡密直接延期（买家免操作）
管理后台列表找到该卡密 → 点「续期」→ 输入延长天数（如 365）→ 买家系统**每 6 小时自动校验一次**，到期前就会悄悄延长，买家无感。

### 吊销（防共享 / 违约处理）
管理后台列表找到该卡密 → 点「吊销」→ 买家系统**最迟 6 小时**（重启立即）校验到失效，业务锁定并提示联系卖家。

## 常见问题（FAQ）

**Q1：我自己家的主系统也要填 LICENSE_SERVER_URL 吗？**
- 你已有的家庭是"老数据"，已自动迁移为长期有效（2099），不受影响，不填也能正常用。
- 如果你以后要**创建新家庭**（比如再给孩子建一个），就必须填 `LICENSE_SERVER_URL=http://127.0.0.1:4444`（飞牛本地地址即可），并给自己发一张卡密。

**Q2：买家激活时报「无法连接卡密服务器」？**
- 说明买家的 NAS 访问不到 `https://lic.你的域名.com`。检查：你的反代是否生效、域名解析是否正确、80/443 端口转发是否成功（用外网手机开 `https://lic.你的域名.com/admin` 测）。

**Q3：买家激活时报「该卡密已激活使用」？**
- 这张卡密已经被激活过了（或买家在别的机器用过）。一个卡密只能激活一次；让买家确认是不是拿错卡，或你另发一张。

**Q4：卡密服务器挂了/离线，买家用不了吗？**
- 已激活家庭**照常能用**到到期日（本地有到期时间，断网宽容模式）。只是"激活新家庭/续费/吊销"需要服务器在线。所以你的飞牛尽量保持稳定，重启飞牛后记得 `docker compose up -d`（已配 `restart: unless-stopped` 会自动拉起）。

**Q5：买家拿到仓库会不会看到你的管理后台？**
- 仓库里确实有 `license-server/` 代码，但买家的 docker-compose 不会启动它，买家也无法用它发卡（卡密数据在你飞牛的 `data/licenses.json`，不在买家机器）。买家最多看到代码，没有你的卡密账本就没用。
