# 买家部署激活手册（照着点就能用）

> 给不会折腾技术的家长看的手册。你需要两样东西：
> 1. **卖家发给你的部署包**（一个 zip 压缩包）
> 2. **卖家发给你的激活卡密**（形如 `MATH-XXXX-XXXX-XXXX`）
>
> 全程不需要敲代码，按下面步骤在飞牛界面里点就行。遇到任何不会的，截图发给卖家远程帮你看。

---

## 第 1 步：把部署包传到飞牛

1. 用电脑浏览器打开飞牛管理界面，进入「**文件**」（File Station）。
2. 在左侧找到存放位置（建议新建文件夹，名字随意，如 `kid-math`）。
3. 把卖家给的 `kid-math.zip` **上传**进去，然后右键 →「**解压到当前目录**」。
4. 解压后应能看到 `docker-compose.yml`、`Dockerfile`、`public` 这些文件/文件夹。

## 第 2 步：启动系统（二选一）

### 方式 A：图形界面（推荐，不用开终端）
1. 飞牛「**应用中心 → Docker**」（或「容器」入口）。
2. 菜单里找到「**项目 / Compose**」（不同版本叫法略有差异，找不到就问卖家）。
3. 点「**新建项目**」→ 项目名随意（如 `kid-math`）→ 文件选择方式选「**从文件导入**」→ 选中第 1 步里的 `docker-compose.yml`。
4. 点「**部署 / 启动**」，等 1~2 分钟（首次要下载运行环境，看网速）。
5. 看到项目状态变「运行中」就成功了。

### 方式 B：卖家远程帮你操作
打开飞牛的「远程协助」或电脑装「向日葵/TV」免费版，把远程码发给卖家，卖家 5 分钟帮你弄好。

## 第 3 步：打开网页激活

1. 在你家局域网内的电脑/平板/手机浏览器，输入：`http://飞牛IP:3333`
   （IP 在飞牛「设置 → 网络」里能看到；如果卖家配了域名，直接用卖家的网址）。
2. 首次打开是「加入家庭 / 创建家庭」两个标签 → 点右侧「**创建家庭**」。
3. 填两样：
   - 家庭 PIN：自己设 4~8 位数字（全家人共用，如 `1234`）
   - 激活卡密：填卖家发你的 `MATH-XXXX-XXXX-XXXX`
4. 点「创建家庭」，显示「✅ 家庭已创建」就激活成功了，有效期一年。

## 第 4 步：家里其他设备加入（手机/Pad）

1. 用手机/Pad 浏览器打开同一个网址。
2. 点「**加入家庭**」标签 → 只输入 PIN → 进入系统。
3. **不需要卡密、不限设备数**，全家几台设备都能用，数据自动同步。
4. 建议在 iPad 上用「分享 → 添加到主屏幕」，以后像 App 一样点开就用。

## 常见问题

**Q1：网页打不开？**
- 手机和飞牛要在**同一个 WiFi/局域网**。
- 确认飞牛 IP 输对了（IP 形如 192.168.x.x）。

**Q2：提示「无法连接卡密服务器」？**
- 你的飞牛需要能上外网访问卖家的服务器。检查飞牛网络是否正常，再试一次。

**Q3：提示「卡密不存在 / 已激活使用」？**
- 卡密填错或已被使用。把提示截图发给卖家，让卖家重新发一张。

**Q4：到期了怎么办？**
- 到期前网页会提示剩余天数，到期后会自动锁定并显示续费页。联系卖家买新卡密，在续费页输入即可。

**Q5：我想换 PIN 或管理孩子/礼品？**
- 网页底部「切换到家长」→ 输入你的 PIN → 家长面板里可以改 PIN、管理礼品、看统计。
