# 小学算术练习系统（儿童友好 · 家庭自托管）

给家里小朋友练算术的小系统：按年级出题（严格不超纲）、练习 / 计时 / 闯关三种模式、积分激励、错题本订正、礼品店兑换。画风针对低龄儿童设计，触屏优先。

## 功能一览
- **按年级出题，不超纲**：覆盖小学 1~6 年级，每个年级的运算范围按课标划定（一年级 20 以内加减、二年级乘法口诀 / 表内除法、三年级多位数乘除、四年级小数加减、五年级小数乘除与分数加减、六年级分数乘除与百分数等）。
- **三种练习模式**
  - 练习模式：做对 +2、做错 -1（积分允许负数）。
  - 计时模式：每题限时，答得越快额外加分（≤3 秒 +2，≤6 秒 +1）。
  - 闯关模式：达到 80% 正确率即「通关」，额外 +10。
- **积分系统**：所有加减写入积分明细，可负；错题本订正正确 +1、订正错误不扣。
- **错题本**：自动收集错题，可一键订正。
- **礼品店**：孩子用积分兑换礼品（扣除积分并记录），家长后台可增删改礼品、**直接换图标、从图标库加更多图标**，兑换后由家长实物兑现。
- **多孩子档案**：首页头像切换，进度 / 积分各自独立。
- **家长面板**（4 位 PIN 保护）：孩子管理、统计（正确率 / 趋势 / 错题数 / 积分明细）、礼品管理、兑换记录（可勾选已兑现）、修改 PIN。

## 本地运行（开发 / 预览）
需要 Node.js ≥ 18。

```bash
node server.js
# 打开 http://localhost:3333
```

默认家长 PIN：`1234`（首次进入家长面板后请修改）。

## 部署到飞牛 NAS
本系统零运行时依赖，打包成一个 Docker 镜像即可。两种方式任选其一。

### 方式一：飞牛图形界面（Docker 套件）

1. **上传项目**：在飞牛「File Station」里新建一个文件夹（如 `kid-math`），把本项目**除 `data/` 以外的所有文件**上传进去（重点：`server.js`、`package.json`、`Dockerfile`、`docker-compose.yml`、`public/` 整个目录）。
2. **构建镜像**：打开飞牛「Docker / 容器管理 → 镜像 → 构建」，选择上传目录里的 `Dockerfile`，镜像名填 `kid-math`，开始构建（约 1~2 分钟，取决于网络拉取 node:18-alpine）。
3. **创建容器**：基于 `kid-math` 镜像新建容器：
   - 端口映射：`3333` → `3333`（容器 3333 映射到 NAS 3333）
   - 存储/卷挂载：把**整个项目目录**以「绑定挂载」方式挂到容器 `/app`，再把 `data` 单独挂为数据卷（compose 已配置好）。这样「一键更新」时 `git pull` 会直接写回 NAS 目录，容器重启即加载新代码。
   - 重启策略：选「始终重启」或 `unless-stopped`
   - 环境变量（可选）：`PORT=3333`、`HOST=0.0.0.0`、`SUPER_ADMIN_PASSWORD=061204`（一键更新的超级管理员密码，可在此改）
4. **启动容器**，点「终端 / 日志」确认打印 `已启动: http://0.0.0.0:3333`。
5. 同局域网的电脑/平板访问 `http://<飞牛内网IP>:3333` 验证能打开。

### 方式二：SSH 命令行（一步到位）

1. 飞牛「设置 → 服务 → SSH」开启 SSH，用终端连上 NAS：`ssh admin@<飞牛内网IP>`
2. 把项目目录拷到 NAS（或从 File Station 上传后 `cd` 进去），进入项目目录后：
   ```bash
   docker compose up -d      # 自动构建镜像并启动容器
   ```
3. 验证：`docker ps` 看到 kid-math 容器 Up 即可，`curl http://localhost:3000` 应有返回。

### 让外网也能访问（域名 + HTTPS）

1. **域名解析**：在域名服务商后台添加一条 **A 记录**指向家里**公网 IP**（动态 IP 建议用 DDNS，飞牛自带 DDNS 或花生壳等）。
2. **端口转发**：登录家用路由器，做端口映射，把 `443`/`80` 转发到飞牛内网 IP 上反代所用端口。
3. **SSL 终止**：在飞牛「反向代理」或安装 **Nginx Proxy Manager** 中新增代理主机，域名填你的域名，转发到 `http://<飞牛内网IP>:3000`，开启 SSL 并用 Let's Encrypt 申请免费证书（需域名已解析且 80 端口可达）。
4. 完成后，平板/手机/电脑用 `https://你的域名` 访问，数据全部同源同步。

### 升级 / 更新
改完代码后重新构建镜像并重启容器即可：`docker compose down && docker compose up -d --build`。数据在 `data` 卷里，不会丢。

## 数据存储说明（v1）
v1 使用单文件 `data/data.json` 存储（挂载到 NAS 数据卷即持久化）。家庭低并发场景下足够。后续如需更强一致 / 并发，可把 `server.js` 中的数据层替换为 SQLite（Prisma），API 与前端无需改动。

## 目录结构
```

public/
  index.html         # 单页应用外壳
  styles.css         # 儿童友好样式

```

## 一键更新（从 GitHub 拉最新版本）

家长面板「⚙️ 设置 → 🔄 一键更新系统」中输入**超级管理员密码**（默认 `061204`，可在 docker-compose 环境变量 `SUPER_ADMIN_PASSWORD` 修改），点击后服务端会：

1. 校验密码 →
2. 在项目目录执行 `git pull --ff-only` 拉取最新代码 →
3. 退出进程，由容器的 `restart: unless-stopped` 自动重启并加载新代码。

**所有已打开的网页会自动刷新**：前端每 15 秒轮询 `/api/version`，发现版本号变化即 `reload()`，因此正在用的孩子 / 家长页面会无缝更新到最新版。

### 飞牛上让一键更新生效的前提
- 项目必须是 **git 仓库**（`git clone` 或 `git init` 后 `git remote add origin <你的仓库地址>`）。
- 容器代码须用 **bind mount**（`./:/app`，compose 已配置），而不是把代码 `COPY` 进镜像——否则 `git pull` 无法持久化。
- 容器内能访问 GitHub（公网可达即可；若 GitHub 慢，也可改用 Gitee 镜像）。
- 首次把代码放到飞牛后记得 `git remote add origin <仓库地址>` 并 `git pull` 一次，保证本地与远程同步。

修改 `SUPER_ADMIN_PASSWORD` 后需重建容器（`docker compose down && docker compose up -d --build`）。
